# Discretionary FX Volatility Catalyst Desk

[![Python 3.10](https://img.shields.io/badge/Python-3.10-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Description:**  
Discretionary macro volatility overlay engine integrating quantitative GARCH(1,1) / LSTM implied volatility predictions with central bank catalyst event windows (Fed, ECB, SARB).

---

## 📌 Architecture & Strategy

This framework bridges quantitative volatility forecasting with human discretionary execution:
1. **Quantitative Signal Layer:** Ingests statistical IV forecasts generated by machine learning/GARCH models and calculates basis-point mispricings relative to market-implied volatility.
2. **Discretionary Macro Filter:** Evaluates policy divergence, regime shifts, and central bank event windows to determine option strategy selection (Straddles, Strangle, Calendar Spreads, or Tactical Pass).
3. **Risk & Execution Control:** Applies regime-dependent position sizing and conviction ratings to prevent trading into liquidity voids or binary structural breaks.
